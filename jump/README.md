# omp-plugin-jump

**Oh My Pi (`omp`) 会话消息导航扩展**

全屏打开当前会话的消息索引：顶部固定列出所有用户消息，下方是按原会话渲染的转录副本。点击顶部任意消息（或按 `↑`/`↓` 选择）即可把转录滚动到该消息的位置。

## 为什么是全屏导航器

`omp` 的对话正文写入终端原生 scrollback，应用无法在其上叠加常驻的、可点击的悬浮层，也无法把终端回滚到指定行。因此插件采用 omp 自身选择器（如 esc-esc rewind）的同一套做法：在备用屏上打开全屏视图，用「置顶消息索引 + 可滚动转录副本」实现同样的跳转体验。按 `esc` 返回原会话，不修改任何会话内容。

## 交互

| 操作 | 说明 |
|---|---|
| `↑` / `↓`（或 `k` / `j`） | 在用户消息间切换，并跳到该消息位置 |
| 鼠标点击顶部消息行 | 跳转到该消息 |
| 鼠标点击转录任意行 | 选中该行所属的用户消息并跳转 |
| 滚轮 / `PgUp` / `PgDn`（或 `K` / `J`） | 滚动转录 |
| `Home` / `End`（或 `g` / `G`） | 跳到第一条 / 最后一条消息 |
| `esc` / `q` / `Ctrl+C` | 关闭导航器 |

打开时定位在最后一条用户消息。

## 安装与使用

```bash
omp plugin link ./jump
# 或
omp --extension ./jump/src/index.ts
```

在任意会话中输入 `/jump`。

## 实现

- `src/index.ts`：注册 `/jump`，快照当前分支的消息条目后，用 `ctx.ui.custom(..., { overlay: true, overlayOptions: { fullscreen: true } })` 打开备用屏视图。
- `src/transcript.ts`：把 `sessionManager.getBranch()` 的消息条目渲染为带颜色、已换行的行数组，并记录每条用户消息的行锚点；工具结果折叠为调用行，thinking 不渲染。
- `src/navigator.ts`：置顶消息带 + 转录视口 + 底部提示；自行解析 SGR 鼠标事件（一次点击会同时到达按下与释放两条报告），按渲染帧的 0 基行号命中测试。

## 已知限制

- 打开期间是快照：会话后续新增的消息需要重新执行 `/jump`。
- 转录为简化渲染：用户文本、助手文本与工具调用各一行/多行，不包含工具输出、图片与 Markdown 样式。
