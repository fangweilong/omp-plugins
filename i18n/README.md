# omp-plugin-i18n

**Oh My Pi (`omp`) 配置项多语言注入扩展插件**

为 `omp` (`@oh-my-pi/pi-coding-agent`) 的全部配置项提供运行时多语言本地化注入。目前完整支持**简体中文 (`zh-CN`)** 与**英文 (`en`)**，支持运行时无缝双向热切换。

---

## 🌟 核心特性

- **无侵入运行时注入**：基于 `omp` 官方扩展体系与 `@oh-my-pi/pi-coding-agent/config/registry`，直接对内存中的 `Setting` 配置句柄进行元数据增强，不修改宿主核心代码。
- **全方位系统级本地化覆盖**：
  - **422 个配置项 (`/settings`)**：标题 (`label`) 与详细解释 (`description`)
  - **10 大顶层面板 Tab**：分类名称本地化 (`appearance` → 外观，`interaction` → 交互等)
  - **59 个功能分组 Group**：组别名称本地化 (`Theme` → 主题配色，`Compaction` → 上下文压缩等)
  - **130+ 枚举选项 (`options`)**：枚举选择项的展示标签与说明文档
  - **181 个斜杠命令说明 (`/` commands)**：自动补全栈式拦截，**仅翻译命令说明/注释，严格保持原始 `/` 命令名称不变** (如 `/model`, `/settings`, `/shake`, `/force` 等)
  - **73 个全局快捷键说明 (`/hotkeys`)**：全量快捷键说明中文本地化 (`KEYBINDINGS`)
  - **6 个内置子智能体描述 (`/agents`)**：子任务 Agent 角色与职责中文定位 (`BUNDLED_AGENTS`)
  - **18 个内置工具参考说明 (`/tools`)**：常用工具的中文功能指南 (`tools.json`)
  - **终端等待加载提示**：动态替换为中文 `思考中...` 状态指示
- **运行时界面文案 (v2)**：在宿主 TUI 渲染时翻译组件自身的文字，不修改语言包以外的宿主状态：
  - **设置面板**：标题、10 个标签栏名称、每页导语、底部快捷键提示、搜索匹配数、状态栏预览标签
  - **工具审批**：`允许工具：bash`、`原因：`、`命令：`、`允许 / 允许一次 / 本会话允许 bash / 拒绝`、`详情`、底部按键提示
  - **工具卡片**：内置工具标题（`Read` → 读取、`Glob` → 查找、`Bash` 卡片命令行）、`运行中…（按 esc 取消）`、`输出 / 耗时 / 超时`、`… 还有 N 行`、`(退出码 N)`、`N 个诊断`
  - **思考块**：`思考中…`、`思考了 12s`、token 计数
  - **加载状态**：`压缩上下文…`、`自动压缩上下文…`、`重试中 · 第 1 / 3 次`、`生成交接文档…`
  - **规划评审**（原生渲染路径）：`计划评审`、`批准并执行 / 批准并压缩上下文 / 细化计划 / 保存并退出`、`复制 / 在 $EDITOR 中编辑 / 取消`
- **双向 100% 确定性回滚**：切换回英文时完全恢复官方原始英文字符串基线，零污染、无副作用；运行时文案在渲染时按当前语言取值，不缓存译文。
- **动态热切换**：提供交互式斜杠命令 `/lang [zh-CN|en|reload]`，即改即生效并自动持久化。
- **自动化维护工具链**：内置提取脚本与校验工具，当 `omp` 版本升级新增配置项时，可一键提取基线并增量同步。

## 🖥️ 运行时文案 (v2)

`src/ui/` 在宿主 TUI 组件的原型方法上安装渲染包装（`render` / `describe`），按当前语言对**组件自身的界面文字**做精确短语或正则替换：

- 短语表、前缀与模式位于 `src/locales/zh-CN/ui-text.json`，`en` 侧只保留同名键的基线（由 `bun run extract` 生成）。
- 只替换字典命中的文字；模型输出、文件内容、diff、终端输出、数学公式与计划正文不会被改写（`md` / `code` / `diff` / `ansi` / `math` 等节点直接跳过）。
- 译文字符串带缓存，语言切换时按 epoch 失效；宿主节点只克隆不改写，因此切回英文无需回滚。

**限制**

- 经典 ANSI 终端路径下，规划评审正文与助手正文保持宿主原文；原生 Tern 路径只翻译结构化节点。
- 依赖 `@oh-my-pi/pi-tui` 的内部导出（已在 **omp 18.12.x** 验证）。宿主若移除某个导出，对应组件自动跳过，不影响插件加载。
- `/lang reload` 会重新读取语言包并重建译文缓存。

## 📦 安装与加载方式

### 方式一：通过插件目录链接 (推荐)

在终端运行以下命令将插件软链接至 `omp` 插件目录：

```bash
omp plugin link ./i18n
```

### 方式二：在全局配置文件中声明

在 `~/.omp/agent/config.yml` 中添加扩展路径：

```yaml
extensions:
  - D:/Codes/other/omp-plugins/i18n
```

### 方式三：单次命令行挂载启动

```bash
omp --extension ./i18n/src/index.ts
```

## 🚀 交互命令

在 `omp` 终端中随时可使用 `/lang` 系列斜杠命令：

| 命令 | 说明 |
|---|---|
| `/lang` 或 `/lang status` | 查看当前生效语言及本地化注入状态 |
| `/lang zh-CN` (或 `/lang zh`) | 即时切换为**简体中文**并保存配置 |
| `/lang en` (或 `/lang english`) | 即时恢复为**原始英文**并保存配置 |
| `/lang reload` | 重新读取磁盘上的 JSON 翻译文件并热应用 (适合开发调试词条) |

### 语言判定优先级

1. **用户运行时指定**：通过 `/lang` 命令选定并持久化在 `~/.omp/i18n.json` 中的设置。
2. **环境变量**：`OMP_LANG` > `LC_ALL` > `LANG`。
3. **系统区域**：自动识别操作系统区域（匹配中文区域则默认启用 `zh-CN`）。
4. **回退保底**：`en`。

## 🔄 升级与维护指南

当 `omp` 官方版本发布升级，可能引入新的配置项或更新文案。使用项目内置脚本保持词库同步：

```bash
# 1. 从当前 omp 运行时提取最新的配置项到 en/，并自动向 zh-CN 补充缺失模板
bun run extract
# 或
omp -p "extract" --extension ./scripts/extract.ts

# 2. 检查翻译完成度与待翻译列表（含运行时文案覆盖率与正则合法性）
bun run check
```

修改 `ui-text.json` 后，可在运行中的会话执行 `/lang reload` 立即生效（会重建译文缓存）。

## 🧩 兼容性

- 运行时文案依赖 `@oh-my-pi/pi-tui` 的内部导出，已在 **omp 18.12.x** 验证；`describe` / `render` 的签名变化会导致对应组件跳过，不影响插件加载。
- 若插件同时通过 `extensions:` 和 `omp plugin link` 注册，扩展工厂通过 `globalThis` 标记只激活一次，语言状态在多个模块实例间共享。
- `/lang reload` 之后，建议重新打开 `/settings` 或再触发一次审批以观察最新译文。
